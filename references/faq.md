# 常见问题速查

## 不会安装 Ollama，也能用吗？
能。先用普通关键词检索完成精读、章节自测、错题复习和进度记录。Ollama 是可选的语义检索增强，不是开始学习的门槛。检索不到时，可换关键词或按章节读原文。

## 第一次用，要准备什么？
提供一本本地书籍或教材，并说“陪我精读”或“用它备考”。已有附件无需反复填写路径。材料不明确时再确认文件；PDF 首次使用按 [PDF 引导](pdf-start.md) 检查组件。

## 为什么 PDF 提示缺少组件？
当前运行技能的 Python 中没有可用的 PDF 读取组件。运行 `scripts/check_environment.py --pdf`，使用输出的安装命令；验证就绪后继续原文件。EPUB/TXT/Markdown 不受影响。不要把组件装到另一套 Python 后就认为已修好。

## 安装失败或没有权限怎么办？
按 [PDF 引导](pdf-start.md) 使用独立环境。不要修改系统 Python 权限。网络暂不可用时保留任务，先提供文本格式材料也能继续。

## PDF 能打开，为什么读不到文字？
它可能是扫描图片，或部分页没有文字层。先做 OCR；加密 PDF 需要有权限的解密或重新导出。安装 pypdf 不等于完成 OCR。

## 文件打不开或出现乱码？
先用普通阅读器确认文件完整。EPUB 重新导出；TXT/Markdown 另存为 UTF-8。技能会保留原文件，不用乱码继续出题。

## 怎么继续上次学习？
说“继续上次学习”。已保存的本地记录可恢复书籍、模式和进度；多本材料时选择一个。此前只在对话里学习、未保存记录时，需要提供上一段进度，不能凭空恢复。

## “考考我”会切换成考试吗？
不会。阅读中的自测用于检查理解，主要反馈理由和思考。只有明确备考目标才进入备考模式，练习成绩分别记录。

## 为什么答对还提示需要澄清？
判断正确可能来自猜测。阅读模式还看理由；补上概念与依据后再评价。开放题允许不同意作者，重点看是否理解观点、论证是否成立。

## 找不到原文怎么办？
换成书中的词，缩小到具体章节，或读取相邻段落。仍找不到就明确说明，不补造出处。语义检索结果也要核对原文。

## 向量服务连不上，会丢进度吗？
不会因此删除学习记录。先用普通检索继续，之后检查服务和模型。服务地址被拒绝时使用自己的本机/内网地址，不关闭校验来绕过限制。

## 换了新版教材，为什么要求重建？
旧索引不再对应新原文。确认后用 `--replace` 重建，保留旧索引备份；旧学习记录不自动当成新教材进度。详见 [材料与检索](retrieval.md)。

## 学习记录和对话都完全离线吗？
索引和进度保存在本地；对话解释使用的模型服务由宿主配置决定。本地保存不代表云端模型永远不会收到引用片段。

## 能保证通过考试吗？
不能。章节练习帮助发现薄弱点；实际考试还受范围、基础和投入影响。未提供官方材料时，生成题标为教材练习。可先看 [完整示例](examples.md) 了解流程。
